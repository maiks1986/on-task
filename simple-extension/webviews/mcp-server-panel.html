Available Tools

The following tools are available in the MCP server:

Server Management Tools

  • server.start: Start the MCP server
  • server.stop: Stop the MCP server
  • server.restart: Restart the MCP server
  • server.status: Get server status

Project Tools

  • project.add: Add a new project
  • project.edit: Edit an existing project
  • project.get: Get project details
  • project.list: List all projects

Task Tools

  • task.add: Add a new task
  • task.edit: Edit an existing task
  • task.get: Get a task by ID
  • task.done: Mark a task as done
  • task.list: List all tasks

Context Tools

  • context.add: Add a new context
  • context.edit: Edit an existing context
  • context.get: Get a context by ID
  • context.list: List all contexts
